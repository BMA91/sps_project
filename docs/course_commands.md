# Course command inventory

This file is a working inventory of shell and scripting commands covered in the course, grouped by chapter. The project should use the commands listed here when possible and only use additional commands when explicitly allowed by the SOP.

## Shell and files
- ls, pwd, cd, mkdir, rmdir, rm, cp, mv, touch
- cat, head, tail, less, more
- grep, sed, awk, cut, sort, uniq
- find, xargs, tee
- tar, chmod, sha256sum, md5sum, cmp
- wc, du, df
- read, export, env, variables, quoting

## System administration
- ps, top, who, id
- chmod, chown, passwd, users
- cron, crontab, service, systemctl

## Scripting
- if, then, else, fi
- for, while, until
- case, select
- functions, arrays, here-docs
- set -euo pipefail
- getopts, trap
- shell script execution and exit codes

## Python (if taught in the course)
- Python 3 basics, argparse, pandas, scipy, matplotlib, pytest

> This is a working checklist. The exact course contents may be refined after the official course PDF is reviewed by the team.
