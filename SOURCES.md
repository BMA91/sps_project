# Sources and dataset provenance

- Dataset: METABRIC (cBioPortal study id: brca_metabric)
- Download URL: https://datahub.assets.cbioportal.org/brca_metabric.tar.gz
- Download date: recorded by the pipeline at runtime
- Access: public cBioPortal study archive, processed clinical data, free access for research and education
- License: original cBioPortal data terms apply; this project uses the public study files only and does not redistribute the raw data beyond the local working archive
- Archive size: reported by the download script after download
- Extraction: clinical files are extracted to data/extracted for local preprocessing only
